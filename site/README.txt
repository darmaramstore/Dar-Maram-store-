Dar Maram Store — fresh static storefront

Deploy with Cloudflare Pages Free using Git integration:
- Repository: darmaramstore/Dar-Maram-store-
- Branch: fresh-free-storefront
- Root directory: site
- Build command: leave blank
- Build output directory: .

The top category navigation and category cards link to the matching sections by anchor. Orders and inquiries open WhatsApp. This is a static catalog starter; real product photos and verified inventory/prices must be added before selling. No card or paid service is part of the source project. Cloudflare plan availability and limits are controlled by Cloudflare.
