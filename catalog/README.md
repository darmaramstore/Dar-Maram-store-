# استيراد كتالوج دار مرام ستور

الملف \`products.csv\` قالب فارغ لبيانات المورد الأصلية. لا تضع بيانات تجريبية أو أسعارًا تقديرية.

## الأعمدة
اسم المنتج، الكود، القسم، السعر، الوصف، المقاس، رابط أو اسم صورة المنتج.

## الأقسام
- الطرح، الإسكارفات، الباندانات، مكملات الحجاب، أو المجموعة: الطرح والإسكارفات والباندانات ومكملات الحجاب
- الملابس الكاجوال
- الشالات أو الشيلان
- العبايات

## الصور
- يمكن إدخال رابط HTTPS للصورة الأصلية، أو اسم ملف صورة موجود داخل \`android-app/app/src/main/assets/products/\`.
- الصيغ المحلية المقبولة: JPG وJPEG وPNG وWEBP.
- لا ينشئ المستورد صورًا بديلة. إذا كان ملف الصورة المحلي مفقودًا، يفشل التحقق بدلًا من عرض صورة غير معتمدة.

## البناء
يشغّل GitHub Actions اختبارات المستورد ثم ينشئ ملف بيانات المنتجات المضمّن في التطبيق. القالب الفارغ ينتج كتالوجًا فارغًا، دون منتجات افتراضية.
